Dashboard de Análise de Rentabilidade e Estoque 📊💰//
Uma ferramenta poderosa e intuitiva, construída em React e Tailwind CSS, para calcular a margem de lucro, gerenciar o estoque e tomar decisões de negócio mais inteligentes.
Dica: Grave um GIF rápido mostrando a aplicação em ação e substitua o link da imagem acima para impressionar os visitantes!
✨ Sobre o Projeto
Este dashboard foi desenvolvido como uma solução one-page, totalmente front-end e sem necessidade de backend, projetada para ajudar pequenos empresários, freelancers e analistas a entenderem rapidamente a viabilidade financeira de um produto.
Com uma interface limpa e reativa, a ferramenta elimina a complexidade das planilhas, oferecendo cálculos em tempo real e insights visuais imediatos sobre custos, margens e o potencial do seu estoque.
Principais Objetivos:
Simplificar: Transformar cálculos financeiros complexos em um formulário simples e direto.
Capacitar: Fornecer dados claros e acionáveis para apoiar decisões de precificação e compra.
Agilizar: Permitir a exportação de relatórios profissionais em PDF com um único clique.

Persistência de Dados: Suas informações são salvas localmente no navegador (localStorage), para que você possa continuar de onde parou.
Tema Claro e Escuro: Alterne entre os modos para melhor conforto visual.
Conteúdo Didático: Clique nos ícones de informação (ⓘ) para entender a fórmula e o significado de cada indicador.
🛠️ Tecnologias Utilizadas
Este projeto foi construído com as mais modernas tecnologias de front-end:
React.js: Biblioteca para a construção da interface de usuário.
TypeScript: Superset do JavaScript que adiciona tipagem estática para um código mais robusto.
Tailwind CSS: Framework CSS utility-first para estilização rápida e moderna.
html2pdf.js: Biblioteca para converter o conteúdo HTML em PDF do lado do cliente.
