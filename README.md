Dashboard de Análise de Rentabilidade e Estoque 📊💰<br>
Uma ferramenta poderosa e intuitiva, construída em React e Tailwind CSS, para calcular a margem de lucro, gerenciar o estoque e tomar decisões de negócio mais inteligentes.<br>
Dica: Grave um GIF rápido mostrando a aplicação em ação e substitua o link da imagem acima para impressionar os visitantes!<br><br>
✨ Sobre o Projeto<br>
Este dashboard foi desenvolvido como uma solução one-page, totalmente front-end e sem necessidade de backend, projetada para ajudar pequenos empresários, freelancers e analistas a entenderem rapidamente a viabilidade financeira de um produto.<br>
Com uma interface limpa e reativa, a ferramenta elimina a complexidade das planilhas, oferecendo cálculos em tempo real e insights visuais imediatos sobre custos, margens e o potencial do seu estoque.<br><br>
Principais Objetivos:<br>
Simplificar: Transformar cálculos financeiros complexos em um formulário simples e direto.<br>
Capacitar: Fornecer dados claros e acionáveis para apoiar decisões de precificação e compra.<br>
Agilizar: Permitir a exportação de relatórios profissionais em PDF com um único clique.<br><br>

⚙️ Recursos Inteligentes:<br>
Exportação para PDF: Gere um relatório profissional do seu dashboard.<br>
Persistência de Dados: Suas informações são salvas localmente no navegador (localStorage), para que você possa continuar de onde parou.<br>
Tema Claro e Escuro: Alterne entre os modos para melhor conforto visual.<br>
Conteúdo Didático: Clique nos ícones de informação (ⓘ) para entender a fórmula e o significado de cada indicador.<br><br>
🛠️ Tecnologias Utilizadas<br>
Este projeto foi construído com as mais modernas tecnologias de front-end:<br>
React.js: Biblioteca para a construção da interface de usuário.<br>
TypeScript: Superset do JavaScript que adiciona tipagem estática para um cód<br>igo mais robusto.<br>
Tailwind CSS: Framework CSS utility-first para estilização rápida e moderna.<br>
html2pdf.js: Biblioteca para converter o conteúdo HTML em PDF do lado do cliente.<br><br>
